# Go Netgear Switch Library — Implementation Roadmap

> **For agentic workers:** REQUIRED SUB-SKILL: Use
> superpowers:subagent-driven-development (recommended) or
> superpowers:executing-plans to implement each slice plan task-by-task.

**Goal:** Deliver the approved spec
(`docs/superpowers/specs/2026-07-30-go-netgear-switch-library-design.md`) in
twelve slices, each merged to `main` via a `--no-ff` merge commit with all
gates green.

**Plan policy:** one plan document per slice, authored **just-in-time** right
before that slice starts (same workflow the Python repo used), so each plan
reflects what earlier slices actually built. This file tracks the sequence and
inter-slice contracts; it is not itself an executable plan.

## Global constraints (apply to every slice plan)

- Module `github.com/mithro/go-netgear-switch-library`, root package
  `netgearswitch`, Go ≥ 1.26, Apache-2.0.
- Parity reference: Python repo branch `fix/live-hardware-parity` @
  `b73e7519776aa6031b4565171f823b997dba9d07` (re-pin on merge). Constants and
  behaviours are ported from the pinned files, never re-derived.
- TDD; small discrete commits; no skipped tests; coverage ≥ 90% on library
  packages; gofmt/vet/golangci-lint clean; `go test -race` green.
- Never more than 3 concurrent subagents. Heavy commands (builds, test runs,
  fake fleets, Python processes) run under `scripts/jail.sh` (systemd-run
  scope: MemoryMax=4G, CPUQuota=400%; ulimit fallback).
- Honesty rules: unsupported capability ⇒ typed error at the earliest point;
  no fabricated values; UNVERIFIED paths gated exactly as Python gates them.
- Temporary files go in `./tmp/` (gitignored), never `/tmp`.

## Inter-slice contracts

- `model` types/errors/registry (slice 1) are frozen interfaces for all later
  slices; changes after slice 3 require touching every consumer in the same
  commit.
- The `virtual` state + endpoint-provider harness (slice 2) is the substrate
  every backend slice (4–7) extends with its face + seeds.
- `gngsw-virtual`'s JSON port-announcement line (slice 8) is the cross-language
  contract consumed by slice 10 and mirrored in the Python-repo PR.
