## Global Constraints

- Wire fidelity is non-negotiable: 32-byte header layout, full-u32 sequence
  field (increment &0xFFFF), `NSDP` signature, end-of-mark FF FF 00 00,
  strict TLV sizes (3B port status, 49B stats, variable-width mirroring),
  v1 XOR auth ("NtgrSmartSwitchRock"), result 0x0700 → typed error naming
  v2, op-check BEFORE result-check.
- Mapping honesty per D-NSDP: admin always true, names nil, speed 0→nil,
  stats have no packet counters (RxErrors=CRC), base MAC UPPERCASE;
  unsupported ops (MACs/LLDP/sensors/PoE via NSDP; PoE/port-admin/VLAN
  lifecycle writes) raise exact Python messages; NSDP has NO reboot op
  (dead-code tlv preserved as unexported if at all — do not invent one).
- Every read prepends Tag MODEL (_with_model rule); verify-after-write on
  all writes; mgmt-IP force-gated.
- The Plus web/NSDP password is ONE shared credential cell (httpPassword)
  feeding both HTTP (slice 06) and NSDP v1 auth — D-NSDP shared-password
  trap.
- Honesty/TDD/race/coverage≥90%/gates/no-stash/trailers as previous slices.
