## Global Constraints

- Five owner principles bind (spec §1.1). Principle 2: HTTP implements the
  full op set the reference does; an op that raises UnsupportedCapability must
  match the reference's exact per-model raise (with its captured-proof
  rationale) — never invent an "unsupported".
- Single-backend dispatch (slice-05b): HTTP registers via
  `RegisterBackend`/`RegisterWriteBackend(model.BackendHTTP, …)`; the
  `reads_verified`/`scheme_verified` gate raises UnsupportedCapability BEFORE
  session build (no CredentialError leak). HTTP uses the `httpPassword` cell.
- Structural HTML quirks are load-bearing (GS110EMX never-closed `<tr>`,
  coordinate-vs-comment cell addressing); reproduce exactly. Go RE2 can't do
  the `_OPEN_ROW_RE` lookahead — manual offset-splitting (D-HTTP-P note).
- Honesty/TDD/race/coverage≥90%/gates/no-stash/trailers as prior slices.
- VLAN membership: reads report the CURRENT/operational view, writes
  target+verify the CONFIGURED view (D-HTTP-F trap — two legitimately
  disagreeing views; do not force them equal).
